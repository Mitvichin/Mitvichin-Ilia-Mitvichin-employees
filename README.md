# Ilia-Mitvichin-employees

Project for Sirma.
This is a simple full-stack application built with **Express** (backend) and **React** (frontend).

## Table of Contents

- [Features](#features)
- [Tech Stack](#tech-stack)
- [Getting Started](#getting-started)

## Features

- REST API using Express
- React frontend with functional components
- JSON data exchange between frontend and backend

## Tech Stack

- **Frontend:** React, Tailwind
- **Backend:** Node.js, Express

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v20+ recommended)
- npm (comes with Node.js)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Mitvichin/Mitvichin-Ilia-Mitvichin-employees
```

2. `cd frontend` and run `npm i`
3. run `npm run dev`
4. `cd backend` and run `npm i`
5. run `npm run dev`

For test run `npm run test`
